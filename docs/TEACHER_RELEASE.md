# Teacher 分支发布说明

该分支发布当前纯 BlinkMimic/BPTT 核心、搬箱适配、奖励和步态改进、测试、配方、G1 资产及最终权重。它基于仓库 main 的历史提交建立，main 的 AMP 实验仍保留在 main 分支；本分支的 src/scripts/tools 是独立的纯版实现。

历史训练为 2026-11-12 的六小时、seed=0、8704 环境，第 25845 轮。最终模型和验证选出的最佳模型相同。实际目标为 48 步 BPTT、0.9 秒未来参考，grasp_place_reach + reference_phase_v3。当前默认配方 32 步不等于历史模型的实际展开长度。

原训练源码快照按用户要求已删除，不将当前源码伪称为原训练源码。发布代码经过普通 Actor/WM/BPTT/保存续训验证，最终权重清理前后逐张量一致，部署 CPU 动作和各项奖励完全一致。模型卡中的历史成绩保留原评估口径，当前缓存协议为 v6。

`results/teacher_025845/release_validation.json` 记录 95 个 CPU 用例、5 个登记 GPU 用例、全部 297400 帧扫描、ONNX 与保存续训结果。完整核心文件 SHA-256 见 source_sha256.json。

本分支包含最终模型对应的裁剪后 NPZ（Git LFS）、数据清单与指纹，不包含裁剪前源录制、训练日志、视频、个人登记资料或认证密钥。更早的历史实验和本机路径仅为文档背景，不表示其材料随本分支分发。
