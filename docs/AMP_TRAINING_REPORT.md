## 学习结果

“完成比例”是独立阶段片段实际运行长度占参考长度的平均值；“未提前失败”按现有物理失败判据统计，二者均不等于三阶段连续成功率。箱体误差及控制惩罚只统计存活步骤；初始策略很快失败，其低箱体误差不代表任务完成得好。

与历史 tracking 相比，推荐 AMP 的共同任务回报 0.6736 低于 0.6920；放置后松手稳定且站立的目标帧比例为 37.03%，高于 25.25%。实际动作加速度也有改善，见下表。本轮尚不能宣称全面超过原方案。

各模式的控制惩罚包含不同分项，表中为各自训练定义的成本；跨模式平滑度使用下方实际动作指标比较。共同任务回报不含 AMP、控制惩罚、新增远距离掌部增益及接近进度，跨版本保持原定义。历史 tracking 使用保存的 10 帧目标、16 步展开和参考动作跳连；比较使用相同任务指标，不是只改变 AMP 的控制实验。

## 训练机制

- 50 Hz，连续 t+0.02…t+0.90 的 45 帧未来参考，32 步实际 BPTT；片段末尾只重复同片段末帧。
- 保留三阶段、箱体目标、深度 latent。actor 无参考关节动作跳连；AMP 模式无机器人身体/root 的逐帧跟踪奖励。
- 独立判别器：相邻状态的躯干相对身体位置、姿态及身体局部线角速度，用掌部替换手腕；单帧 195 维，相邻状态与阶段条件 393 维。
- 专家仅来自关节限位投影和 FK 后的 748 条 train。阶段匹配，阶段内均匀选片段和相邻帧，不跨片段；val/test 不进入判别器训练。
- 1024–512–256 ReLU，Adam 1e-5、batch 256、每轮一次，标签 ±1；归一化输入上的专家梯度惩罚系数 10，D/GP 使用 FP32。
- 采集→WM→D→actor 32 步 BPTT→同次混合奖励的 detached GAE critic；前 200 轮只更新 WM/D。actor 更新冻结 WM/D/CNN 参数和归一化统计，保留输入梯度。
- 新 AMP 目标位置相对实际机器人根部，保留参考 yaw 坐标；4056 维布局不变。旧模型缺省 reference 原点，按保存参数评估。

## 确认并修复的问题

| 问题 | 修改与核验 |
|---|---|
| 没有完整 32 步起点时采样报错 | 先检查有效起点；准备好前继续采集/WM/D。CUDA graph 权重使用固定存储 |
| 双手仍贴箱却记作松手/起身 | 实际离箱、箱体稳定、站高和直立共同判断；参考松手后关闭掌部约束 |
| 脚滑项可通过抬脚降低接触估计，抵消起身梯度 | 接触估计停止梯度，保留速度梯度；站立方向回归通过 |
| 窄高斯掌部项在几米外无有效梯度 | 接近阶段 75% 窄核 + 25% 0.5 m 逆二次核，保持上限和共同任务指标 |
| 未来目标相对参考位置，机器人缺少实际落后误差 | carry_goal_anchor=robot，采集/想象/评估/ONNX 统一；旧模型保留原语义 |
| 长距离接近收益不足、策略走得不足或原地停留 | 加入有符号、有上限的实际接近进度，尺度来自训练专家数据 |
| 混合检查点评估共用首配置、批量漏项、已结束世界 NaN 污染 | 按保存配置分组，共用 CarryEvalMetrics，使用 where 屏蔽结束世界 |
| 检查点/推理兼容 | 保存 D/归一化/优化器/更新次数；拒绝不匹配输入或目标语义，actor/ONNX 无 D 依赖 |

进度项仅在接近阶段、参考尚未要求抓箱时启用：以转移开始时同一箱体位置计算根部水平距离减少量，距离下限 0.6 m，按 0.3 m/s 封顶、权重 1。静止 0、后退负、箱体单独移动不能领奖，近处/抓箱关闭。训练专家首次接触距离 P10/P50/P90 为 0.399/0.459/0.538 m，平均接近速度中位数 0.291 m/s；见 [尺度依据](../results/amp_seed0_2h/approach_progress_design.json)。

组合检查：AMP 和搬箱项均有明显正贡献，控制成本未吞没全部任务收益；搬运阶段主要控制成本为脚滑。起身仅在放置末段的适用帧启用，全段均值较小，其目标帧指标已单列。箱体奖励直接对箱体状态求导，需要 WM 的动作—物体动力学传回 actor，局部 joint 梯度为零不等于断链；进度项经根部位移/WM 回传。不适用阶段或重置后屏蔽历史的分项为零，符合定义。

全部 13 次验证及一次独立测试共抽查 1534 个策略实际访问转移，各项和组合梯度全部有限。最大误差：奖励分解 2.38e-07、梯度分解 4.77e-07、CPU 重算与真实端 4.25e-05。actor 裁剪前梯度日志范围 2.924–190.776，有尖峰，未出现非有限更新；style-only 经冻结 WM/D 的非零 actor 梯度由测试另行核验。正确局部梯度不保证长时任务已经收敛，长接近波动已保留。

## 吞吐、验收与交付
