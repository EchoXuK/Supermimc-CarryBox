本次运行入口为 `logs/gait_reference_20261112_0101`。最新数据固定为 748/146/106 条、297400 帧；运行使用该目录的 `data/` 副本，不跟随外部数据的后续编辑。完整 SHA-256、裁剪记录和逐文件清单见 `dataset_fingerprint.json`、`data_provenance/`。

本轮已完成 7936 环境、从零 7200 秒纯 BlinkMimic 训练及全部验证/测试和六段视频。**同脚二次点地改善目标未达标**：全测试相同时间前缀中，抬箱/搬运/放置重复落地对每分钟分别从 6.29/6.21/1.38 增至 8.54/9.99/1.98；腿部高频能量与合并额外回落有所下降。三阶段宏成功率由 91.11% 升至 95.98%，但搬运成功率由 93.83% 降至 88.89%。不推荐全面替换旧最佳，默认仍兼容 legacy。详见 实验报告（历史本机材料） 与 最终审查（历史本机材料）。

## 奖励

后续六小时纯 BlinkMimic 实验采用 `--carry_reward_profile grasp_place_reach` 与
`--carry_gait_profile reference_phase_v3`。两者均为显式的新配置，旧配置数值定义保持不变。

抬箱阶段新增参考同帧的根部 XY 与手箱相对位置惩罚：`0.02 * 0.5 * E/(1+E)`，
根部 `E=||p_xy-p_ref_xy||²/0.30²`，手部对左右手分别计算
`E=||(p_palm-p_box)-(p_ref_palm-p_ref_box)||²/0.10²` 后平均。
两项仅用于 stage 0，合计每秒最多扣 1 分，专家状态新增罚为零。
采用参考相对位置而非静态吸引箱体，保留演示接近/伸手的时序；有理函数尾部用于补充
远距离时原高斯手部奖励接近零的梯度。原抓放三项惩罚继续使用，`task_norm_return` 不变。

v3 保留 v2 的足底高度、速度分开计算，将各自与腿速的 `1-exp(-E)` 替换为
`0.75*(1-exp(-E)) + 0.25*E/(1+E)`。近零斜率仍为 1，大误差梯度不再按指数消失；
仍然有界、参考误差为零时最优，不强制左右交替。接触概率项、尺度和权重不变。

该实验最大 BPTT 展开为 48 步（0.96 秒），未来参考仍为 0.9 秒，
`--min_imagination_steps 32 --min_reset_steps 32` 保留最短 33 帧参考的参与机会。
参考末帧后冻结想象状态，Actor 只累计一次到达末帧的奖励；Critic 的归一化包含一次
终态，拟合掩码排除末帧之后的重复转移。Critic minibatch 保持固定形状以避免随有效
窗口长度重编译。默认不指定 `min_imagination_steps` 时保留原全长起点采样行为；
续训校验该配置。WM 探针同步报告到 48 步的开环误差。

上述机制针对已观察到的反馈缺口，实际抬箱成功率及二次点地效果须由后续训练评估确认。

后续实验支持 `--carry_gait_profile reference_phase_v2`。它保留接触与腿速项，仅将足底运动项改为高度和速度分别饱和后相加：`P = mean(1-exp(-e_z) + 1-exp(-e_v))`。尺度仍为 1.5 cm、0.30 m/s，P 的权重仍为 0.50，P 的范围变为 [0,2)。这防止较大的速度误差通过 `exp(-e_v)` 把高度纠正梯度压至零，也防止高度误差屏蔽速度纠正。旧 `reference_phase` 的联合指数保持原义；新 profile 独立进入检查点、续训校验、评估分组和缓存身份。专家自身新增罚仍为零，总训练回报上界不变。后续实验目录为 `logs/gait_continuation_20261112_090448`；上轮的“未达标”结论保留，不能提前把这次机制修正称为步态已修复。

`--carry_gait_profile legacy` 保留原脚部奖励；旧检查点缺少该字段时仍按 legacy 读取。`reference_phase` 替换原踝高匹配与绝对低足速奖励，保留原身体/根部/箱体/手部奖励和 `grasp_place` 惩罚。`--carry_gait_scale` 默认 1，必须有限且非负。

从 MJCF 提取每脚四个球形足底碰撞垫；共享一次 FK 计算球底几何位置和球心速度。世界向下的半径偏移为常数，因此几何位置的时间导数等于球心速度。它们是几何探针，不是真实接触力。

每段参考以左右两脚足底最低点的全段 5% 分位数校准同一个平地高度，避免短片段中始终悬空的脚被错误标成支撑。实际和参考均使用 `sigmoid((0.008 - 相对地面最低高度)/0.004)`。

令 C 为实际与参考逐脚接触概率的均方误差；P 为足底点的 `1-exp(-((z-z_ref)/0.015)^2-||v-v_ref||²/0.30²)`，沿两脚四点平均；V 为十二个腿关节的 `1-exp(-(qd-qd_ref)²/1.0²)` 的平均。每控制步扣除：

```
0.02 * carry_gait_scale * (0.50*C + 0.50*P + 0.25*V)
```

专家状态的三项新惩罚均为零。速度目标来自当前参考帧，正常摆动和脚跟/脚尖滚动不会被一律要求静止。保留原动作变化与关节限位惩罚，额外 residual-rate、residual-acceleration 和全关节速度项本轮均为零。

真实采集与 BPTT 调用同一个奖励头。`task_norm_return` 继续剔除训练脚部奖励及所有新增 shaping，最大原任务奖励仍为每步 `9.5*0.02`。reference_phase 不再把旧脚部正奖励加进训练上界。检查点参数、续训校验、批量分组和评估缓存均包含新配置。

## 步态指标

原来的额外抬脚指标只计高出参考 4 cm 的踝部移动，不能检验低幅度二次点地。新增指标从 50 Hz 原始状态计算：整脚接触采用 8/15 mm 滞回，脚跟和脚尖采用 5/10 mm，均需连续两帧确认。参考与实际逐脚进行最大匹配数、再最小时间误差的事件匹配，容差 120 ms。80 ms 内同脚的整脚/脚跟/脚尖事件合并计数，同时保留各区域明细。

报告多余重新接地、同脚重复落脚、漏迈步、摆动中断、匹配时间误差、支撑足速及腿部 HF6。专家本来就有的重复落脚不会按多余事件计；不强制左右交替。超过 120 ms 的相位偏移也可能被分成未匹配回落与漏步，需结合整脚重复序列和视频区分，不能把所有脚跟/脚尖事件叫作完整重复迈步。指标剔除最多 0.5 秒起始稳定段与 0.24 秒终止段，按有效秒数归一，并保留逐事件时间戳。足部几何事件必须结合视频解释，不能等同于接触冲量。

## 审查中修复的接口问题

训练真实采集与想象轨迹统一使用 `[-20,20]`。最终审查进一步发现，独立评估和视频直接调用环境时曾绕过采集器裁剪，`out['a']` 本身也没有边界保证。现在在 `TrackingSim.step_core` 的 PD 入口统一裁剪，PD 目标、奖励、下一步动作历史和输出记录共享该动作；输入张量不原地修改。CPU 与实际 GPU 的边界回归均通过。评估协议现为 v6，并包含动作边界，防止旧缓存复用。此前未裁剪结果已归档、撤回，所有候选、历史基线与视频重新生成。

精确两小时训练使用 `source_v7`，训练两条路径原已裁剪，权重有效；最终评估使用 `source_v8`，包括这个评估入口修复及首窗日志修复。二者差异保存为 `postrun_evaluation_boundary_fix.diff`，不修改原训练快照。

新诊断记录每项奖励的环境均值/标准差、动作饱和比例，20 分钟探针另计算各奖励的 Actor 梯度、任务与步态梯度余弦、合成比例，以及 WM 在 4/8/16/32 步的足底高度与速度误差。探针保存并恢复随机状态、requires_grad 与已有梯度，不执行优化器更新。

梯度归因使用与 Actor 目标完全相同的 `gamma^t * c_t` 权重；审查时补上了初版诊断遗漏的折扣因子。首次采集前保存 CPU 参数副本，每次验证记录五个模块相对上次的参数 L2 改变量，避免将有限梯度误认为有效更新。

精确训练源码冻结为 `source_v7`，最终评估源码为 `source_v8`，指标版本为 2。指标分类修正了“脚跟腾空、脚尖仍支撑”被误称为整脚摆动中断的问题：使用参考整脚接触状态，检测阈值及额外回落定义一致。相关回归已通过，基线在最终快照上重新评估。512/1024 环境早期基准使用 v3，后续部分档位使用 v5/v6；v3 之后仅改监控和评估，训练奖励与优化目标相同，最佳三档用最终版本重新测量。

完整监控冒烟还发现：`--compile_more` 包装了共享的观测、参考和奖励方法，初版梯度探针的小批量重算仍会进入这些包装，先长时间编译，再因编译反向图不支持 `retain_graph=True` 而失败。v7 在探针期间暂时使用三个方法的原始 callable，并在 `finally` 恢复原包装、参数开关和已有梯度；不改变训练的编译路径。成功及异常路径的恢复回归均通过，原失败登记与修复记录保存在 `monitor_recompile_issue.json`。

训练完成后的首窗审查还发现，总奖励保留了回放预热，而分项诊断在预热后被单独清空。主工程已改为保留同一批预热样本；实际奖励和优化器更新不变。原始首窗保留、从归因比较排除，其余窗口的奖励重构最大误差约 1.17e-7。精确实验仍由冻结 `source_v7` 复现，日志修复另存 `postrun_logging_fix.diff`。

## 裁剪尾部的重置采样修复

`reference_phase_v2` 后续试验在约45分钟主动停止：已裁剪片段会留下只有1个可用转移的尾桶，但旧基础先验给每桶相同权重，短回合首步的实际动作变化惩罚又被回合均值 bootstrap 外推。第3250轮检查点的内部EMA最大权重为74.4%；计入基础、课程和失败混合后，实际下一次重置有40.2%的概率落在仅剩1步的桶。独立2353个结束回合诊断中，1125个只运行1步；这些短回合只占全部诊断转移约0.67%，不能将回合占比解释成同等比例的训练转移浪费。

本轮启用 `--min_reset_steps 32`。随机训练起点必须至少保留32个参考转移；33帧片段仍有1个合法起点。基础先验按合法起点数分配桶权重，保留每片段及每阶段原有总概率；所有课程、失败与聚焦分支在抽样前共同过滤无效桶。实际数据过滤478个不足窗口的桶，748个训练片段均保留，三阶段基础先验仍各占1/3。

尾帧仍由轨迹正常到达、终止和计奖，物理失败也可提前结束；没有删除首步动作成本或修改奖励。`--min_reset_steps` 默认1，保持旧采样语义；旧检查点缺字段时按1续训，新窗口写入检查点并校验续训一致性。评估仍从片段首帧开始，推理不使用训练重置限制。

修复后的训练重新随机初始化和计时7200秒。数据与原快照指纹一致；复用已确认的显存范围，重测7680/7936/8192/8448/8704环境的完整更新与邻档。原中止轮次、源码和登记保留，实际结果见 `logs/gait_reset_window_20261112_105113`，不把中止轮次当作完成两小时实验。
